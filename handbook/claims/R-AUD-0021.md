# Each Pro-Q 3 band has its own stereo placement: left, right, stereo, mid or side

## Claim

A Pro-Q 3 band works on both channels by default; its stereo placement setting makes it process only the left, right, mid or side signal, so the mid (mono) can be filtered apart from the side (stereo).

## Covers

Where one band acts in the stereo image; fixing something that lives only in the sides or only in the middle.

## Does not cover

Whether a given track needs it: that comes from the audit's width and correlation readings, and a band is placed only for a named problem.

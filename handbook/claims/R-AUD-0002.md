# EBU R 128: programme loudness -23.0 LUFS, true peak not above -1 dBTP, loudness range per Tech 3342

## Claim

For broadcast production the EBU normalises programme loudness to -23.0 LUFS (tolerance ±1.0 LU where the target is not practically attainable), keeps the true peak level at or under -1 dBTP measured per BS.1770, and measures loudness variation as Loudness Range per EBU Tech 3342. The recommendation exists because peak normalisation produced large loudness differences between programmes.

## Covers

The origin of the -1 dBTP ceiling Marco uses by default and of the LRA number in the audit; the broadcast target.

## Does not cover

Music streaming targets (R-AUD-0003); a loudness target for a demo or a release, which is the artist's references, not this number.

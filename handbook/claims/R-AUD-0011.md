# True peaks are inter-sample peaks; true peak limiting with 4x oversampling and 0.1 ms lookahead keeps them within 0.1 dB

## Claim

A D/A converter or a lossy encoder can produce an analog peak above the sample peaks; True Peak Limiting in Pro-L 2 reduces existing true peaks and attenuates the overshoot its own limiting adds, so the output stays under the Output Level in dBTP; 4x oversampling with at least 0.1 ms lookahead keeps inter-sample peaks within about 0.1 dB; for EBU R128 the Output Level is -1 dBTP, for a streaming master -14 LUFS with Output Level -1 dBTP is the maker's guidance.

## Covers

Why the ceiling is a true-peak ceiling and how Marco sets the limiter to hold it.

## Does not cover

The platform ceilings themselves (R-AUD-0002, R-AUD-0003).

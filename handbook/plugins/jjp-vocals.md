# Waves JJP Vocals (claim R-AUD-0020)

The color box on the artist's vocal chain (taste pass, 2026-11-02: Lows
-20.8, Highs 37.6, De-Esser 32.1). From the user guide installed on this
Mac, read 2026-11-02.

## How Marco reasons with it

- **Type**: Male, Male 2 or Female for the voice on the take; JJP's defaults
  per type are the starting point.
- **Sensitivity**: set on the loudest section of the take until the LED
  reads yellow; the same rule as the master's checks, the loudest part first.
  This is the one control the guide defines in full, and the one Marco sets.
- **Main Section** (dynamics and EQ, "all processing is influenced by this
  section"): the guide installed here does not define Lows, Highs,
  De-Esser or the rest in numbers, so Marco keeps the artist's own values
  on them and writes "kept, the artist's" in the log; a change there is his
  word or a bench print, never a guess.
- **Center faders**: aux returns with their own processing, pre-fader, each
  with a mute; a return the part does not need is muted, which is a measured
  decision (print with and without).
- **Output**: the Master fader down when the Clip LED lights.

## Verify

The take's level into the next plug-in unchanged by more than 0.5 dB after
a sensitivity move; the Clip LED dark on the loudest section.
